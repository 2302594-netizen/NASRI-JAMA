How to open
-----------
Unzip the folder and open index.html in a browser.

Pages
-----
index.html    Home
about.html    About Us
menu.html     Menu
gallery.html  Gallery
contact.html  Contact and Reservations
events.html   Events (extra page)

Notes
-----
- Only HTML and CSS are used. All styling is in css/style.css.
- Flexbox is used for the navigation, cards and footer. CSS Grid is used for the gallery.
- Extras: events page, fade-in animation on the hero text, embedded map on the contact page.
- The map needs an internet connection to load.
- Colour palette is my own: forest green (#1F4D3A), soft cream (#F4F6EE) and gold (#E0A526), set as variables in :root.
- Every page has a hero section with its own photo (hero.jpg, hero-about.jpg, hero-menu.jpg, hero-gallery.jpg, hero-contact.jpg).
- Images were taken from the page designs in the assignment document.
- Fonts are loaded from Google Fonts (Playfair Display and Open Sans).

Validation
----------
HTML: all six pages checked with the W3C Markup Validator (Nu Html Checker). No errors, no warnings.
CSS:  css/style.css checked with the W3C CSS Validator. No errors, no warnings.
